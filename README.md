# Makkabi × Kerri Kuzbyt — Pitch

Interne Entscheidungsvorlage für den Vorstand/das Gremium von Makkabi Frankfurt (Basketball): Einladung der Trainerin **Kerri Kuzbyt** für zwei Leistungscamps und zwölf Monate Trainer-Mentorship.

## Live

- **Entscheidungsvorlage:** https://dsgngee.github.io/makkabi-kuzbyt-camp/
- **Präsentation:** https://dsgngee.github.io/makkabi-kuzbyt-camp/praesentation.html

## Inhalt

| Datei | Zweck |
|---|---|
| `index.html` | Entscheidungsvorlage (Langform, zur Weitergabe ans Gremium) |
| `praesentation.html` | Foliensatz für die Präsentation (Pfeiltasten/Scroll) |
| `styles.css` | Gemeinsames Design („Taktiktafel": Navy / Basketball-Orange / Kreide) |

## Bearbeiten

Reiner HTML/CSS-Stand, kein Build nötig. Lokal die `index.html` im Browser öffnen oder per GitHub Pages ausliefern (Settings → Pages → Branch `main` / Ordner `/root`).

## Hinweis

Alle Zahlen sind vorläufig und vor Beschluss zu bestätigen (Reisekosten, Kostenstruktur Normalcamp). Angaben zu Kerri Kuzbyt stammen aus öffentlich zugänglichen Quellen; Honorar/Programm aus dem Angebot an Makkabi. Dieses Repo enthält interne Kalkulationsgrößen und ist bewusst öffentlich gestellt.
